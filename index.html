          지금 볼 만한 공고

            넣기 전에 꼭

            • 특별공급은 세대당 평생 한 번만 당첨될 수 있어.
            • 당첨되면 재당첨 제한이 걸려 (규제지역은 최대 10년). 계약 안 할 곳은 넣지 마.
            • 부양가족은 실제로 같이 살아야 인정돼. 위장전입이 걸리면 당첨이 취소돼.

            청약홈 API 키

            Decoding 키를 붙여넣어. 이 폰에만 저장돼

            키 받는 방법 (5분)
            1. 공공데이터포털(data.go.kr)에 회원가입하고 로그인해.
            2. 검색창에 청약홈 분양정보 조회 서비스를 검색해. (한국부동산원 제공)
            3. 활용신청을 누르고 목적에 “개인 청약 일정 확인”이라고 적으면 바로 승인돼.
            4. 마이페이지 → 개발계정에서 일반 인증키(Decoding)를 복사해 위 칸에 붙여넣어.
            5. 승인 직후엔 키가 등록되기까지 1~2시간 걸릴 수 있어. 오류가 나면 조금 있다 다시 눌러봐.

            관심 지역

            고른 지역 공고만 보여줘. 아무것도 안 고르면 전국.
